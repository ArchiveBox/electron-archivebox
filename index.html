ArchiveBox · Electron desktop app

Your web archive.
On your desktop.

A simple desktop window for ArchiveBox on Windows and Linux. Save websites, browse your collection, and manage your local server without living in a terminal.

On a Mac, iPhone, or iPad? ArchiveBox.app is our recommended native experience.

Keep a local copy

Add URLs and preserve pages in your own ArchiveBox collection. Your archive stays in your local archive folder.

Browse what you saved

Search your collection, open snapshots, and inspect the files that ArchiveBox captured.

Manage your server

Watch current jobs in Activity, start and stop ArchiveBox, and manage server settings and user access.

Download ArchiveBox Desktop

This app uses Docker to run ArchiveBox locally. Install and start Docker before opening ArchiveBox Desktop.

Windows.exe installer↓🐧Linux.deb · Debian / Ubuntu↓🐧Linux.rpm · Fedora / RHEL↓Mac.dmg disk image↓

The Mac download is the Electron fallback. For the native Mac, iPhone, and iPad experience, choose ArchiveBox.app.

  1. Install Docker Desktop on Windows, or Docker Desktop / Docker Engine on Linux.
  2. Download the installer for your platform above, install it, and open ArchiveBox Desktop.
  3. Open the app, create your local administrator account, and start ArchiveBox. The first launch downloads the ArchiveBox Docker image.

ArchiveBox Desktop is an experimental fallback for Windows and Linux, using the current ArchiveBox development backend. For Apple devices, use ArchiveBox.app. You can also use ArchiveBox Server directly in your browser.
