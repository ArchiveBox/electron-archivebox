ArchiveBox runs locally using Docker. Install and start Docker Desktop, then choose an administrator account to manage your archive.

Use at least eight characters. You will use this account to sign in to ArchiveBox.

Settings

Your archive is stored on this computer. Docker runs the ArchiveBox service in the background.

Network access

Local access stays available. All interfaces exposes your archive to devices that can reach this computer. A base URL sets the address used in links; HTTPS requires your own reverse proxy.
