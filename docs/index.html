Download ArchiveBox Desktop

This app uses Docker to run ArchiveBox locally. Install and start Docker before opening ArchiveBox Desktop.

Windows.exe installer↓🐧Linux.deb · Debian / Ubuntu↓🐧Linux.rpm · Fedora / RHEL↓Mac.dmg disk image↓

The Mac download is the Electron fallback. For the native Mac, iPhone, and iPad experience, choose ArchiveBox.app.

  1. Install Docker Desktop on Windows or Mac, or Docker Desktop / Docker Engine on Linux.
  2. Download the installer for your platform above, install it, and open ArchiveBox Desktop.
  3. Open the app, create your local administrator account, and start ArchiveBox. The first launch downloads the ArchiveBox Docker image.

Your collection stays in ~/archivebox. The local server opens on port 5797, matching ArchiveBox Server. In Settings, choose access from this computer only, your local network, or a custom interface, and set the port and public URL. Installers are unsigned, so your operating system may ask you to approve the app on first launch.
