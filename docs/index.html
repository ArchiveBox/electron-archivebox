Get started on Windows or Linux

This app uses Docker to run ArchiveBox locally. Install and start Docker before opening ArchiveBox Desktop.

  1. Install Docker Desktop on Windows, or Docker Desktop / Docker Engine on Linux.
  2. Check available desktop downloads. Development builds are also available from the CI build artifacts (GitHub sign-in required).
  3. Open the app, create your local administrator account, and start ArchiveBox. The first launch downloads the ArchiveBox Docker image.

ArchiveBox Desktop is an experimental fallback for Windows and Linux, using the current ArchiveBox development backend. For Apple devices, use ArchiveBox.app. You can also use ArchiveBox Server directly in your browser.
